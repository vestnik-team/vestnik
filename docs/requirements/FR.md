# Функциональные требования (FR)

## Покрытие штатными средствами OJS

| Значок | Значение |
|---|---|
| `+` | Есть в OJS, включая настройку штатных средств. |
| `+-` | Частично есть: требуется проверить недостающую часть и определить настройку, готовый плагин или доработку. |
| `-` | Требуется реализовать отсутствующую функцию: подобрать подходящий плагин или разработать расширение. |

## Вопросы для уточнения формулировок

- Определить обязательные метаданные, допустимый состав LaTeX-пакета и правила проверки файлов для FR-1.2–FR-1.3.
- Определить число рецензентов, сроки, регламент напоминаний и правила повторных приглашений.
- Определить все действия через почту для каждой роли. Текущий список не покрывает все действия редактора через почту и поэтому ещё не обеспечивает BR-02 полностью.
- Определить источники и состав миграции, формат отчётов и критерии сверки.
