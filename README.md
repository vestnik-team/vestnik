# Вестник НГУ — локальное окружение OJS

OJS 3.5.0-5 и MariaDB 10.11 запускаются через Docker Compose. У каждого разработчика своя база и свои файлы. При первом запуске на пустой базе скрипт создаёт таблицы OJS и администратора сайта. Основной язык — русский, дополнительный — английский, часовой пояс — Asia/Novosibirsk.

## 1. Подготовьте проект

Запустите Docker, затем проверьте доступность движка и Compose.

```sh
docker info
docker compose version
```

Если проекта ещё нет на ноутбуке, получите его и перейдите в корневой каталог.

```sh
git clone https://github.com/vestnik-team/vestnik.git
cd vestnik
```

## 2. Заполните .env

При первом запуске выполните `cp .env.example .env`. Если у вас уже есть локальный `.env`, сохраните его и используйте прежние реквизиты базы. При существующей установке OJS сохранится и прежняя учётная запись администратора.

Откройте `.env` в редакторе. В репозитории хранится шаблон с пустыми значениями.

| Переменная | Значение для локального стенда |
| --- | --- |
| OJS_BASE_URL | `http://localhost:8080` |
| OJS_DB_HOST, OJS_DB_PORT | `db` и `3306` |
| OJS_DB_NAME, OJS_DB_USER | Например, `ojs` в обоих полях |
| OJS_DB_PASSWORD | Пароль пользователя MariaDB для OJS |
| DB_ROOT_PASSWORD | Отдельный пароль администратора MariaDB |
| OJS_ADMIN_USER, OJS_ADMIN_EMAIL | По умолчанию `admin` и `admin@example.test` |
| OJS_ADMIN_PASSWORD | Для новой установки задайте пароль администратора OJS длиной от 8 символов. Он понадобится для первого входа |
| SMTP_HOST, SMTP_PORT, SMTP_USER, SMTP_PASSWORD | Для локального запуска оставьте пустыми. Без SMTP почтовые сообщения записываются в журнал. Для внешней почты укажите реквизиты своего сервера |

Пароли с символом `$` или `#` в `.env` заключайте в одинарные кавычки. Для стенда с данными MariaDB использует пароль, заданный при первом создании базы.

## 3. Запустите OJS и дождитесь установки

1. В терминале из корня проекта выполните:

   ```sh
   sh start.sh
   ```

2. Оставьте терминал открытым. Пока сайт запускается, в терминале появляются точки. Когда сайт ответит, появится строка с адресом из `OJS_BASE_URL`. Пример для стандартной конфигурации:

   ```text
   OJS готов → http://localhost:8080
   ```

   Команда завершится сама. Контейнеры продолжат работать в фоне.

3. Откройте адрес из строки **«OJS готов»** и нажмите **«Войти»**. Для первого входа используйте логин и пароль из `OJS_ADMIN_USER` и `OJS_ADMIN_PASSWORD` в вашем `.env`. Если логин оставили пустым, введите `admin`. При повторном запуске используйте прежние данные для входа.

**Готово**, если после входа вы видите раздел **«Администрирование»**.

## Повторный запуск

Для остановки выполните `docker compose stop`, для запуска — `docker compose up -d`. При перезапуске сохраняются база, ключ приложения, учётные записи и вложения. Настройки подключения из `.env` применяются после пересоздания контейнера командой `docker compose up -d`. Данные первого администратора нужны только при установке. Флаг `-v` в команде `docker compose down -v` удаляет тома с данными.

## Рабочие папки расширений

Для исходников расширений предложен каталог `plugins/` в корне проекта. Структуру рабочих папок и способ подключения определяет [задача № 44](https://github.com/vestnik-team/vestnik/issues/44).
